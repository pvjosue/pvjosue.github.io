Suggestion per contrast

How each contrast looks

Simulation: the wall’s ambient light lifts every black to a grey. Real eyes adapt, so the brightest area reads as white. Dark details (blue glow, dark bars) vanish first at low contrast. Real facades add texture and colour tint.

Calibration (home test)

  1. Small projector, plain light wall, room as dark as you like. Note its real ANSI lumens (Eco/Bright mode as used).
  2. Project a full-white image. Measure image width, height and the distance to the wall (m).
  3. phyphox Light: phone flat on the wall, sensor facing the projector. Projector off: read Eamb (room light as it will be).
  4. White image on: read centre + four corners, enter all five.
  5. Black image on: same five points.
  6. Press Apply: η goes into the main calculator. Use Copy to keep the values for later.
\[ \eta=\frac{(\bar E_{white}-\bar E_{black})\,A_i}{\Phi},\quad CR_{room}=\frac{\bar E_{white}}{\bar E_{black}},\quad U=\frac{E_{min}}{\bar E_{white}} \]

The last applied calibration is also remembered in this browser.

Formulas

\[ W_i=\max\!\Big(\tfrac{W}{n_x-(n_x-1)o},\; a\,\tfrac{H}{n_y-(n_y-1)o}\Big),\quad A_i=\tfrac{W_i^2}{a} \] \[ TR=\frac{D}{W_i}\qquad D\in[TR_{min}W_i,\;TR_{max}W_i] \] \[ CR=\frac{E_{amb}+E_{proj}}{E_{amb}}=1+\frac{\eta\,\Phi}{A_i\,E_{amb}}\;\Rightarrow\;\Phi_{req}=\frac{(CR-1)\,E_{amb}\,A_i}{\eta} \] \[ k=\Big\lceil \frac{\Phi_{req}}{\Phi_{proj}}\Big\rceil\ \text{(stacked per tile)},\qquad L_{white}=\frac{\rho\,(E_{amb}+E_{proj})}{\pi} \]

a = projector aspect ratio, o = overlap fraction, Φ in ANSI lumens. Contrast is independent of ρ (Lambertian); ρ only sets absolute brightness L in cd/m².
