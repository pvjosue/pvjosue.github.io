Live Scoring · Side-Screen Results

A simple phone-based judging workflow for competition day, with event scores shown on a dedicated screen.

Delivery time
4–6 weeks
Event length
1 day
Planning budget
Up to €500 with a venue screen; up to €600 if rental is needed
Audience
Judges, athletes, organizers and spectators

Idea

Judges enter attempts and scores through a simple phone-friendly interface, with event results shown on a dedicated screen. This is a lightweight event setup, without a hosted results service or a separate organizer dashboard.

Judge phone interface

A basic scoring workflow for attempts, tops, zones and time, matched to the event's rules.

Results screen

Show event scores on a venue screen or a rented screen/beamer.

Delivery & budget

Allow 4–6 weeks to agree the scoring format, prepare the phone interface and screen display, then test with sample event data. Include a rehearsal before competition day.

Scoring workflow and mobile interfaceUp to €250
Screen layout, testing and event setupUp to €250
Screen/beamer rental (if needed)€100
Total with venue screenUp to €500
Total with rentalUp to €600

Planning estimate for one competition format and event. Rental is only needed if the venue has no suitable screen/beamer. Venue network upgrades, event crew and integration with an existing scoring platform are separate.

Requirements & risks

  • Agree on scoring rules and the simple score-correction process before the event.
  • Reliable venue Wi-Fi is preferred; prepare an offline and manual backup process.
  • Test judge phones and the display with sample event data before competition day.

Value

  • Makes event scores easier to follow on a screen.
  • Judges can enter scores from their phones.
  • Scores can be used in projection and stream graphics if show integration is selected.
