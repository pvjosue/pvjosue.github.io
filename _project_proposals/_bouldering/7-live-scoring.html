Real-time Leaderboard & Scoring

Judges enter scores on their phones while athletes climb; event scores can be shown on a venue screen.

Delivery time
4–8 weeks
Planning budget
Up to €500 with a venue screen; up to €600 if rental is needed. Show integration is scoped separately.
Audience
Judges, athletes, organizers and spectators

Idea

A simple phone-friendly judging workflow lets judges enter event scores for display on a venue screen. Optional projection or stream graphics are scoped with the selected Comp Day Show.

Tiers

Tier 1 · Side-screen results

Basic phone scoring workflow and results display on an existing or rented screen.

Tier 2 · Integrated show

Use event scores in the interactive competition show and stream graphics, scoped with the selected Comp Day Show.

How it works

  • Judges use a mobile web interface; no app-store install is required.
  • Scores follow the agreed event format and are shown on the venue screen.
  • Score corrections follow a simple event process, without a separate organizer dashboard.
  • An offline procedure and manual backup protect the event if venue connectivity fails.

Delivery & budget

Tier 1 · Side-screen results4–6 weeks · up to €500 with venue screen (+€100 if rental is needed)
Tier 2 · Integrated show6–8 weeks · show integration scoped with the Comp Day Show

Tier 1 estimate is for one competition format and event. Venue screen/beamer rental is €100 if needed; travel, event crew and integration with an existing scoring platform are separate.

Requirements & risks

  • Competition rules, judge roles and simple correction workflow need to be agreed before the event.
  • Reliable venue Wi-Fi is preferred; a tested fallback is required.
  • Any connection to an existing federation or gym scoring system depends on its available integration interface.
  • Run a full rehearsal using the actual event format before competition day.

Value

  • Clearer event scores for athletes and spectators.
  • Judges enter scores from their phones.
  • Scores can be used in the show and stream when that integration is selected.
