Run Comparison Tool

Compare any attempt with an earlier run, synchronized in time.

Length
Ongoing
Budget
€5k–12k
Audience
Recreational climbers, competitive climbers, coaches, gym networks

Idea

The permanent version of the finals Live Replay. Any climber compares their attempt with an earlier run (their own, a friend's or a pro's), superimposed with synchronized time, on a screen or on the wall between attempts.

Side-by-side overlay

Two runs on top of each other, with the time gap highlighted.

Technique analysis

Coaches review progress, efficiency and technique session by session.

Cross-gym duels

With a network of gyms, runs on the same problem can be shared remotely for leagues and challenges.
